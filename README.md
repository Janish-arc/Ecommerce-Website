# 🛒 E-Commerce Web Application

A full-stack E-Commerce web application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. This platform provides a seamless online shopping experience with product browsing, authentication, cart management, order processing, and an admin dashboard.

## 🚀 Features

### 👤 User Authentication
- Secure user registration and login.
- JWT-based authentication.
- Role-Based Access Control (RBAC).
- Protected routes and API endpoints.

### 🛍️ Product Management
- Browse and explore available products.
- Dynamic product filtering and sorting.
- Product catalog management.
- Detailed product information.

### 🛒 Shopping Cart
- Add products to cart.
- Update product quantities.
- Remove products from cart.
- Manage cart items efficiently.

### 📦 Order Management
- Place and manage orders.
- Track order information.
- Handle order-related operations.

### 🔐 Admin Dashboard
- Manage products and product categories.
- Manage customer orders.
- Control application resources through role-based access.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Janish-arc/Ecommerce-Website.git
```

### 2. Navigate to the Project

```bash
cd Ecommerce-Website
```

### 3. Install Dependencies

Install dependencies separately inside your frontend and backend directories.

```bash
cd backend
npm install

cd ../frontend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in your backend directory and configure your MongoDB connection string, JWT secret, and other required environment variables according to your backend configuration.

### 5. Run the Application

Start the backend and frontend using their respective development scripts.

```bash
npm run dev
```

*Note: Update the directory names and commands if your project uses a different structure or startup script.*
